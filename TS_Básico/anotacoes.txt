npm install typescript --save-dev     (instala o TS e adiciona as dependências)
npx tsc --init (iniciar a configuração do typescript - tsc é o compilador do TS)

"exclude": ["node_modules", "dist"],
"esModuleInterop": true    (typescript melhor interatividade com módulos terceiros).

npm install -D @types/node

Problemas de tipo: npm i @types/react

npm install ts-node --save-dev

Em package.json, alterar "scripts": {"dev": "nodemon --loader ts-node --esm server.js"}

Em tsconfig.json: "allowJs": true
